# Changelog

## 0.2.0

- Turkish output (`--lang tr`, picked automatically from a Turkish locale) and a Turkish README.
- `catalog` command that lists every achievement with tiers, how to earn it and tips.
- Achievement guides in English and Turkish, generated from the catalog.
- SVG card (`--format svg`) with light, dark and automatic themes.
- Markdown output and support for several usernames at once.
- GitHub Action to keep a card in your profile README up to date.
- Tips under each achievement that isn't maxed out yet (`--no-tips` to hide them).

## 0.1.0

- First version: terminal report and JSON output.
